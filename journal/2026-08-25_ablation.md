# 2026-08-25 — Loss Ablation Results (FSC147 val, cached features, 384 input)

## Setup
All experiments: frozen DINOv3 ConvNeXt-tiny backbone, cached 56x56 features, 40 epochs, AdamW lr=1e-3, warmup2+stable10+cosine. GPU: RTX3060 12GB.

## Results

| Experiment | Config | Best MAE (raw) | Δ vs Baseline |
|---|---|---|---|
| **Baseline** | den=1, cnt=1, sim=0.8, ot=0.05 | **19.65** (Ep28) | — |
| **No OT** | den=1, cnt=1, sim=0.8, ot=0 | **19.15** (Ep16) | -0.5 |
| **No Sim** | den=1, cnt=1, ot=0 | **19.22** (Ep16) | -0.4 |
| **No Density** | cnt=1, sim=0.8, ot=0 | **21.30** (Ep20) | +1.7 |
| **Count Only** | cnt=1, ot=0 | **20.90** (Ep9) | +1.3 |
| **No Count** | sim=1, ot=0.5 | **47.09** (Ep5) | +27.4 |

## Conclusions

1. **Count loss = sole core**: removing it breaks everything; alone achieves ~20.9
2. **OT = completely useless**: removing it improves MAE by 0.5 (noise in cost matrix)
3. **Sim ≈ useless**: removing it barely changes MAE (-0.4, within noise)
4. **Density = weak help**: removing it degrades MAE by +1.7
5. **Optimal config = cnt + density only**: simplest effective model

## Architecture Decision
Removed SimModule, PileHead, OT coverage loss, UOT loss from model.py.
Simplified model: backbone → fuser → condenser → density decoder. Loss = MSE(density) + smooth_L1(log(count)).
