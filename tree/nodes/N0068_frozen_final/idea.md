# N0068_frozen_final — 冻结 backbone + 末层 hs(3,4) 读取

## 目的（对照实验）
N0066 (mid-FT) 早停差 +6.02，但把"读中间层"和"解冻 backbone"两个变量绑在了一起，无法归因。
本节点**正交化**：backbone 完全冻结，仅 head 改读**末层 hs(3,4)** (384,768)，
与冠军 N0054（冻结 + 中间层 hs(2,3), 19.65）形成干净对照，单独检验：
**中间层 vs 末层，哪个特征更适合计数（排除解冻混淆）。**

## 假设 H0095
IF 读取末层 hs(3,4)（backbone 冻结），THEN val MAE 相对 N0054（中间层冻结）差异由特征语义决定。
- **CONFIRM** 若 <19.45：末层特征显著更优 → H0095 "末层更适" 成立，值得末层+FT 方向
- **TIE** 19.45–20.15：中间/末层特征等价 → 证实 N0066 的差源于"解冻"，与读层无关
- **FAIL** 若 >20.15：中间层特征本身更强（或末层 1/32 分辨率语义不足）→ H0094 "final worse" 支持

## 方法
- 基座 = N0067 model（已支持 hs(3,4)→96 分辨率插值，Exemplar 读 768ch）
- 与 N0067 唯一差异：`tune_stages=[]`（全冻结）
- Head/优化器与 N0054 完全一致（head lr=1e-3，backbone 无梯度 → 单 LR group）
- 30ep @384 与 N0054 相同

## 预期科学价值
N0054/N0068 做层对照（冻结、干净），N0066/N0067 做解冻对照。
四格表补全最后一格：冻结+末层。
