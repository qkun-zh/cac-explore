## 3-lens reasoning

- **Lens 1 — math of conditional capacity:** let base density logits be D0 and the expert residual be R with per-image gate g in [0,1], output D = D0 + g*R. With zero-init out-conv, R=0 at step 0 so D=D0 exactly (clean null). Expected risk splits as E[L(D0)] + E[g*L_tail(R)] because g~0 on sparse images kills the second term there while opening it on dense images. Routing proxy is stop-gradient (detach), so dL/dtheta_base gets no routing-Jacobian term and dL/dtheta_gate flows only through the scalar gate head — no 1/sd or 1/temp second-gradient path into simprior projections (the N0008 NaN mechanism). Capacity is allocated where MSE saturates (peaks clipped by the single 96x96 cond path), not spread uniformly.
- **Lens 2 — champion lineage (why this, why NOT calibration/similarity):** per-image diagnostic: error heavy-tailed and count-correlated — top 1% val images ~=30% of total |Δ|, gt>500 (17 imgs) mean |Δ| ~=511.7 severely UNDER-counted; N0002 simprior gain was broad, not tail. Similarity-side-into-cond family is 4x dead: H0004 timeout-null (token-max einsum blowup), H0005 refuted +1.02 (proposal-verification), H0006 catastrophic +25.28 (shared qproj reuse starvation), H0007 refuted +5.07 + 23-NaN tail (undetached S recompute + std Jacobians, q/k -18%/-33%, temp 0.0393->0.0255). N0008 synthesis section 4.1/4.2 therefore bans any second gradient path into simprior projections. Oracle-affine global count calibration is proven dead (best oracle affine on val worsens MAE — no headroom), so H0009 is NOT a global rescale c*D or bias: it is additive localized peak capacity routed by a detached proxy, silent on sparse images.
- **Lens 3 — counter-intuitive / low-cost:** ~4.3k actual params inside the booked 8k envelope (two 1x1 expert convs 64->32->64 ~=4.2k + single-linear gate head ~=0.1k; head ~=3.529M -> +0.004M; node total ~=31.349M <= 32M). Counter-intuitive bet: adding capacity ONLY for ~17/val catastrophic images moves global MAE by >=0.30, because those images dominate the sum. Cheap falsification: gate-never-opens or expert-norm-stays-near-zero reads as mechanism rejection with the confirmed similarity readout undisturbed (own params only, decoder in_ch untouched, append-only RNG).

## ONE targeted change spec (coding contract)

- Add single switch `use_densexp` (default False; parent behavior byte-identical when False). When True, construct ONE post-decoder expert module AFTER all parent modules (append-only RNG order preserved; decoder `in_ch` stays 192; no change to cond/simprior/decoder constructors).
- Forward: take post-decoder density logits (or joint density-logit feature at final resolution) + a frozen-context read; compute a per-image dense-level proxy scalar UNDER stop-gradient (detach; e.g. detached pooled statistic of cond/density field — no grad into simprior, no S recompute, no qproj/kproj contact in forward or backward); map proxy through a single linear + sigmoid to gate g in [0,1]. Expert = two 1x1 convs (64->32->64, own weights only) ending in a zero-initialized out conv (weight and bias = 0), producing a same-shape residual R on density logits. Output density logits = base logits + g*R.
- Null/ablation: flag off -> exact parent forward; flag on at init -> all-zero residual (zero-init contract). No shared projection, no temperature touch, no global affine/count rescale.
