## 1. Survey note (web-first, 2 searches + 2 verification fetches; informs, first principles decide)

The claim that *count/scale-conditional shaping of exemplar similarity* is real, current and accepted:

- Ref A — **GeCo2: Generalized-Scale Object Counting with Gradual Query Aggregation** (Pelhan et al., AAAI 2026; arXiv:2511.08048; code github.com/jerpelhan/GECO2). The current few-shot-counter SOTA narrative: scale is the binding failure, dense small-object regions are exactly where heuristics (upsampling/tiling) are needed, and the fix is scale-conditioned *query aggregation* (scale-specific exemplar prototypes → gradual cross-scale query construction). Supports the premise that exemplar-similarity paths must be scale-conditional, and that dense regions specifically need it.
- Ref B — **SQLNet: Scale-Modulated Query and Localization Network for Few-Shot Class-Agnostic Counting** (Wu et al.; arXiv:2311.10011). Scale-modulated exemplars-unified query correlation: exemplar scale is injected into the query/correlation stage and used as supervision. Count/scale conditioning of the matching signal is an active, accepted design direction.
- Ref C — **FamNet: Learning To Count Everything** (Ranjan et al., CVPR 2021; arXiv:2104.08391). The origin of exemplar scaling: multi-scale exemplar correlation maps (scales 0.9 / 1.1) rather than tuning hardening — scale-aware correlation is where FSC-147 gains came from (Table 4).
- Ref D — **Zhai et al. (ICML 2023): Stabilizing Transformer Training by Preventing Attention Entropy Collapse** (arXiv:2303.06296). Defines entropy collapse as pathologically concentrated, near-one-hot attention and proves a tight attention-entropy lower bound that decays *exponentially fast* in the spectral norm of the attention logits; temperature is the lever (dividing logits by temp directly controls entropy). This is the degeneracy our ledger already replicates empirically in simprior's softmax-over-K (temp 0.07→0.0393, →0.0214, →0.0033, →0.0044).
- Ref E — **Hong & Lee (EMNLP 2025): Variance Sensitivity Induces Attention Entropy Collapse and Instability in Transformers** (ACL Anthology 2025.emnlp-main.421, DOI 10.18653/v1/2025.emnlp-main.421). Attributes collapse to softmax's variance sensitivity: the exponential over-amplifies logit differences, so attention "disproportionately concentrates on a single token"; entropy-stable reweighting / variance control keeps it healthy. Direct support that *removing a free softmax temperature's runaway from the joint loss* — rather than adding yet another free parameter to adapt under it — is the alignment-correct fix.
- Ref F — **Masarczyk et al. (2025): Unpacking Softmax: How Temperature Drives Representation Collapse, Compression, and Generalization** (arXiv:2506.01562). Temperature is not a free accuracy knob; it *drives representation-level collapse* (rank deficit bias) and generalization. Direct theoretical backing for the H0010 reading that the parent's collapsing temp is not an under-tuning artifact but a temperature-driven representational failure that a deterministic, input-anchored surrogate should replace. (NOTE: the working brief listed this ID for Hong & Lee; verified on arxiv.org/abs/2506.01562 that it is this Masarczyk et al. paper — cited here under its correct paper, Honest Fix to the brief.)

What the survey establishes for the novelty gate: scale-conditioned similarity is accepted and current in CAC (A, B, C), and emergent softmax-temperature collapse is a recognized forward-transformer degeneracy with explicit temperature-remediation precedent (D, E, F). The gap: nobody renders the count/scale condition deterministically *into the confirmed exemplar-similarity readout's evidence and temperature* as stop-gradient per-image surrogates with a byte-identical step-0 — a closed-door derivation would be insufficient novelty; these real mechanisms transfer.

## 2. Mechanism design — `use_counttau` (exact math)

Everything below attaches to the **confirmed SimPrior readout** (`model.py:193-221`) and conditionally modifies only the two quantities the readout computes: the evidence channels `ev = cat([top1, cons])` and the softmax temperature `temp` (divisor, `model.py:207,217`). `fine` and `e` stay read-only; `qproj`/`kproj`/`out` untouched; no shared projection, no new branch.

**Count surrogate (per image, stop-gradient):**
```
g_I = log(1 + fine.detach().mean(dim=1).clamp_min(0).sum(dim=(2,3)) / (Hf*Wf))      per image i
```
`fine` is the FineFuser field (B,128,96,96); `.detach()` kills any gradient path through the surrogate so the simprior projections get no routing Jacobian (the N0008 NaN mechanism and the H0006 shared-projection starvation are structurally impossible); `.mean(dim=1)` collapses channels to a non-negative spatial map; `.clamp_min(0)`, then spatial sum normalized by `Hf*Wf = 9216`; `log(1+·)` compresses range. `g_I` is a scalar per image (B,) — a self-measure of object mass: dense images have more supthreshold fine energy.

**Calibrated evidence and temperature:**
```
ev'  = ev  * exp(w_g * g_I)
tau' = tau * exp(w_t * g_I)
```
with `w_g, w_t` **zero-init scalar parameters** (created AFTER all parent modules, appended last, AGENTS §5 rule 13). Broadcasts: `exp(w*g_I)` is (B,1,1,1), `ev` is (B,2,96,96), `tau` is scalar divided per-cell as in the parent. `tau'` replaces `temp` in the softmax-over-K (`W = (S/tau').softmax(dim=1)`); `ev'` replaces `ev` before the zero-init readout proj.

**Step-0 byte-identity (def-use check the Coding Agent must run):** at `w_g=w_t=0`, `exp(0)=1`, so `ev'=ev`, `tau'=tau` — the child's forward is numerically identical to the parent's on every step-0 input. The required check: instantiate both `Counter(cfg_parent)` and `Counter(cfg_child)` at `use_counttau=false`, same seed, and assert the forward outputs (`density`, `n_aux`) are bit-identical; then `use_counttau=true` at init must also equal the parent (zero-init contract). Flag-off path adds zero ops.

**Why this is NOT a repeat of the four refuted families:**
- (i) **Not a free learnable temperature.** The thing that collapsed under joint loss is the single shared `temp` exposed to the optimizer (H0005/H0008/H0009/H0007 corpus). Here no new free multiplier is added: `w_g` scales the *evidence* and `w_t` scales *temperature*, but both are input-anchored and detached — the gradient they carry is bounded and per-image real (∂/∂w_t ∝ g_I·log-multiplier), not a sharpening runaway that can hit a clamp floor, and neither feeds back into `qproj`/`kproj`.
- (ii) **Not exemplar gating.** The §11 ban is pre-condenser exemplar gating at any granularity (channel / per-exemplar / image-global gates on `e` or `fine`). `use_counttau` gates nothing: it leaves `e` and `fine` untouched and *scales the confirmed readout's two established outputs* by a measured count proxy inside SimPrior.forward. Dense images get `ev'` up-weighted (small-object similarity mass grows: w_g>0) and hot-softmax entropy restored via `tau'` (dense images re-soften: w_t>0) — opposite of the near-one-hot commitment that starves them.
- (iii) **Parameter-isolated.** Two scalars plus one detached forward reshape. No tensors shared with `Condenser`, `GCA`, or `SimPrior.qproj/kproj`; no second qproj; no einsum growth; can't repeat the H0006 catastrophic shared-projection starvation or the H0004 budget blowup. Isolation check at verdict: `qproj`/`kproj` norms and `temp` trajectory must match the parent, else the run is a harness failure, not a verdict.

## 3. Expected failure modes + why each is an accepted risk

- **w_g saturates to a constant** (→ `exp(w_g·g)` degenerates to a single global scale `c·ev`). That is the "constant count gain" collapse: per-image conditioning is lost, behavior ≈ a constant evidence multiplier — which is exactly a free-scale readout, i.e. H0001-with-a-scalar, and should read as mechanism failure. **Check:** distribution of `w_g·g_I` over a val sweep at verdict; near-zero per-image spread = rejected.
- **g correlates with nothing** (surrogate variance does not track count) → `w_g,w_t` stay ≈ 0 → null-and-dragging: forward ≈ parent, booked bars unmet. H0009 showed this exact quiet-null failure mode; it is accepted because a clean, engaged-but-worse result is still a falsification, and the isolation checks (temp off-floor, norms matched) tell us it is the surrogate's fault and not readout corruption.
- **w_t drives tau' off the intended band** (whiplash between softened and hardened per-image). Risk is bounded because `g_I` is clamped-postive-subthreshold and `log(1+·)` compresses; still, monitor `|log(tau'/tau)|` and the fraction of val images at the clamp floor — floor fraction must drop vs parent, not spread.
- **Mitigation is monitoring, not new mechanism:** log/tenboard `w_g`, `w_t` norms, `g_I` histogram (dense vs sparse), and fraction-at-floor, all vs the parent's temperature band.

## 4. Testable predictions beyond MAE

1. **Dense-tail |Δ| drops:** gt>500 mean |Δ| falls below the 511.7 baseline (this is half the booked bar — the mechanism is *designed* for catastrophic dense images, not for global tweaks).
2. **w_g > 0 (mass on):** the evidence-gain weight must be decisively positive and the per-image spread of `w_g·g_I` meaningful — evidence up-weighting on dense images is the claimed active path, not a frozen constant.
3. **No floor-collapse:** the temperature path stays bounded — `|log(tau'/tau)|` on dense-val stays < 2 (i.e. nowhere near the 11.8×/9× collapses of H0008/H0009), and the fraction of val images pinned at the 1e-3 floor shrinks below the parent's.
4. **Difficulty-bin spread shrinks:** val MAE across count/difficulty bins narrows (error mass leaves the catastrophic tail for the mid-range), not just a global level shift.

## 5. Honest risks / confounders + isolation protocol

- **Joint MSE(+w_cnt·L1) absorption:** the L1 count-anchor (weight 0.4) is image-global; if it can satisfy itself by other channels (GCA count weigfactor, decoder scale), the per-image surrogate gain could be absorbed with `w` ≈ 0 — a false-null. **Isolating protocol:** child vs parent under the **same v2 protocol (augment=true), same seed 20260830, same 32ep/1800s budget**; both from current canonical baseline, never absolute-level cross-protocol comparisons (AGENTS §6 verdict semantics). Compare, in one run pair: final EMA val MAE, dense-tail |Δ|, temp/floor fraction, w norms. A child that matches the parent while `w_g·g_I` spread is non-trivial ⇒ mechanism engaged but inert (surrogate not binding) ⇒ refutation; a child that matches with `w≈0` ⇒ surrogate dead on arrival ⇒ refutation with a different diagnosis; either way the confirmed readout's own metrics must match the parent (harness-failure gate).
- **Protocol re-instantiation caveat (AGENTS §7):** 22.5641/22.26/511.7 are pre-v2 (augment=false) historical numbers; v2 re-instantiates the canonical baseline and the bars are restated in the verdict evidence note with both numbers.
