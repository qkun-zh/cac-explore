## §2 — Exact mechanism: CountAnchor — stop-gradient box-unit-mass scale on the residual

### 2.1 The measured scale-free flaw (the raison d'être, with numbers)

Parent N0015 `SimPrior.forward` (model.py:225–252) computes, end to end:

```
q, p → S (cosine, [-1,1]) → top1, cons → ev = cat([top1, cons])
     → cellcal: ev *= exp(w_c · log1p(mhat))          # mhat mean-1, RELATIVE gain
     → peakcal: ev *= g (≈1, dead code, w_p≈0.0017)
     → return self.out(ev)                             # zero-init 1×1, 2→64
# CountingHead: cond_map = cond_map + that residual    # model.py:175-185
# decoder: cat([fine, cond_map]) → density             # model.py:186
```

### 2.2 The anchor (exact math)

Inside `SimPrior.forward`, immediately before `return` (i.e. AFTER the untouched cellcal/peakcal blocks), a new independent block only reached when `use_canchor=True`:

```
# new kwargs: bboxes=None, img_size=None, use_canchor=False
if use_canchor and bboxes is not None:
    t = top1.detach().clamp_min(0)                         # (B,1,96,96) stop-grad, positive part
    tmin = t.amin(dim=(2, 3), keepdim=True)
    tmax = t.amax(dim=(2, 3), keepdim=True)
    t_mm = (t - tmin) / (tmax - tmin + 1e-6)               # spatial minmax → [0,1]
    s = t_mm.shape[-1] / float(img_size)                   # 96/384 = 0.25
    idx = torch.arange(t_mm.shape[0], device=bboxes.device, dtype=bboxes.dtype).view(-1, 1, 1).expand(-1, bboxes.shape[1], 1)
    rois = torch.cat([idx, bboxes * s], -1).reshape(-1, 5)  # same roi convention as ExemplarEncoder model.py:95-96
    z = roi_align(t_mm, rois, output_size=(1, 1)).view(B, K, 1, 1, 1).mean(dim=1)   # (B,1,1,1)
    alpha = (1.0 / (z + 1e-6)).clamp(0.25, 4.0)             # CountingDINO eq.1 direction: divide by z
    res = self.out(ev) * alpha                              # scale the RESIDUAL, not ev, not gain
    return res
return self.out(ev)                                         # flag off → parent line byte-identical
```

- **What is scaled:** the returned residual (post-`out`), so the parent cellcal/peakcal/`out` lines are executed unchanged and only the final amplitude moves. Scaling `ev` pre-`out` would interact with the learned `out` bias (`W·(α·ev)+b` ≠ `α·(W·ev+b)`); post-`out` scaling moves the whole count-bearing term, bias included.
- **Stop-gradient everywhere:** `top1.detach()`, no grad through `alpha`, no grad to `qproj`/`kproj`/`fine` from the anchor, no grad to `bboxes`. The anchor is a pure routing-free measurement (not a gate, not a mask, not a route — it never selects or suppresses a substrate; it multiplies the SAME parent residual by a continuous scalar on ALL images).
- **Bounds:** `alpha ∈ [0.25, 4.0]` (finite, guarded; a blind box can boost residual at most 4×, an oversaturating box can cut it at most 4×). `t_mm` guarded by `+1e-6`. `roi_align` on `(B,1,96,96)` with `output_size=(1,1)` is an adaptive mean per box — no new dependency (roi_align already imported, model.py:15).
- **Gradient to the residual path:** `∂res/∂θ_out = alpha · ∂out/∂θ_out` — the confirmed `out` still trains from the live loss on every image; `alpha` only re-weights per-image contribution, exactly like a per-image sample weight derived from data (no learned scalar, no count surrogate, no regime split).
- **Count-bearing claim (testable):** `z` measures in-box response of the model's own matcher; `alpha = 1/z` is CountingDINO's normalization direction (response weak in the known-object boxes → amplify residual; response strong → tame it), so the residual's amplitude is pinned to "unit mass per exemplar object" instead of to the arbitrary scale of cosine/mean-1 fields.
