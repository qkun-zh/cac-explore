# GOD v7 — 单层不平衡最优传输计数损失

> v7 2026-08-25。相对 v6 的修订全部来自 G001_god_hf 实证（E1–E24）+ 根因分析
> （`docs/GOD_root_cause_2026-08-25.md`）与三版本对照（`docs/GOD_solver_versions.md`）。
> 变更摘要见文末 §版本史。数学排版从简，一律用纯文本记号。

## 1. 问题形式化（同 v6）

模型预测 M 个沙堆 S={(w_j,p_j)}_{j=1..M}，w_j>0 为质量，p_j∈R² 为坐标。
真实标注 N 个坑 G={g_i}_{i=1..N}，每坑容量归一化为 1。
传输量 π_ij ≥ 0 为堆 j → 坑 i 的质量；剩余 s_j = w_j − Σ_i π_ij ≥ 0；
坑 i 实收 R_i = Σ_j π_ij。d_ij = ‖p_j − g_i‖² / S²（S=图像边长，做尺度归一）。

## 2. 单层不平衡 OT 目标（v7 核心修订，替代 v6 双层分解）

v6 把 β/γ 放在内层 argmin 之外，导致内层解不知道缺额有成本（不自洽，见根因 D3）。
v7 改为**单层**：β/γ 折进同一个 min，即严格的 L2 松弛不平衡 OT：

```
min_π≥0   α·Σ_ij π_ij d_ij + ε·Σ π_ij(log π_ij − 1)
          + β·Σ_i (1 − R_i)²        # 缺额+溢出对称二次罚（v7 起）
          + γ·Σ_j s_j²              # 剩余销毁罚
```

对 π 求解后，外层仅余互斥项：
```
L_total(π*) = α⟨π*,C⟩ + βΣ(1−R*)² + γΣs*² + Lrep({w,p})
```

### 2.1 对称惩罚（修订 v6 的"无溢出惩罚"论证）
v6 `:33-34` 的"最优解天然 R≤1"仅在**内层被精确求解**时成立。
近似求解器（有限迭代 K）下不成立，实证中 over 单批冲到 41。
**v7 规则：缺额与溢出对称惩罚；只有当内层收敛判据满足（如 K≥20 且边缘残差<tol）
才允许关闭溢出项。**

### 2.2 软松弛取代硬约束（修订 v6 `:53`）
`Σ_i π_ij ≤ w_j` 硬不等式在 log 域 Sinkhorn 中没有闭式 proximal 步，
且 w→0 时可行集退化。v7 改为软松弛：行边缘违反全部计入 s_j 并受 γ 罚，
不再保留显式硬约束。π≥0 仍由 exp 参数化自动保证。

## 3. 沙堆空间互斥正则（同 v6）

Lrep = λ Σ_{j<k} w_j w_k exp(−‖p_j−p_k‖²/(2σ²))，σ 取 median(exemplar框宽高)/S，下限 8px。

## 4. 可微实现：log 域 KL/L2 混合不平衡 Sinkhorn（替代 v6 朴素 Sinkhorn 表述）

行边缘 a=w_j，列边缘 b_i=1。对偶变量 f∈R^M, g∈R^N，K≈5–10 步展开进计算图：

```
重复 K 次:
  f ← ρ₁/(ρ₁+ε) · ( −ε · LSE_n[ (g_n − C_mn)/ε ] )     # 行更新（含 a_m 的 log 项并入 f 初值）
  g ← ρ₂/(ρ₂+ε) · ( −ε · LSE_m[ (f_m − C_nm)/ε ] )     # 列更新 ← 坑侧协调的关键步
π_mn = exp((f_m + g_n − C_mn)/ε)
R_n = Σ_m π_mn ;  s_j = w_j − Σ_n π_jn
```

- ρ₂ ↔ β（坑侧/缺额+溢出），ρ₁ ↔ γ（堆侧/剩余）。ρ→∞ 退化为平衡 Sinkhorn。
- KL 形式给出干净闭式迭代；L2 铰链版需逐元素解标量方程，工程上以 KL 近似并在日志标注偏离。
- 全部 K 步 unrolled，梯度经整条迭代链回传至 {w,p}（值函数包络梯度，非路由器梯度）。

## 5. 计数读出（双读出协议）

- **闭卷（部署）**：N̂ = Σ_j w_j —— 不依赖 GT 坑。
- **开卷（诊断上界）**：N̂⁺ = Σ_ij π_ij = Σ(w−s) —— 用 GT 坑位置。
训练目标仍是开卷一致性；闭卷与开卷的 gap 是"总量校准"的进度表。
评估两路都报（bucket 化），部署只认闭卷。

## 6. 关键性质（v7 修订版）

1. 单层自洽：β/γ 进入同一 min，内层解直接感知缺额/溢出成本（修 D3）。
2. 对称惩罚：deficit 与 overflow 同时在场（修 D2，推翻 v6 无溢出论证的适用范围）。
3. 软松弛可微：无硬约束，log 域迭代数值稳定，AMP 下须 fp32 子图或 logsumexp 实现（修 D1）。
4. 端到端可微：K 步展开的包络梯度回传至骨干。

## 7. 已知偏离教科书 uOT 之处（诚实清单）

- 边缘 a=w 由网络预测（学习式边缘）、支撑点 p 可学习（变支撑）——uOT 扩展，无收敛理论保证。
- ε 与 C 的尺度耦合敏感：d²/S²∈[0,1] 时 ε≈0.05 偏尖，需随 σ_box 重调。
- KL 近似 L2 铰链（§4 注）。
