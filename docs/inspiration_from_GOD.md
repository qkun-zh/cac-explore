# 不平衡最优传输计数损失

## 1. 问题形式化

设模型预测 M 个沙堆，记为 S={(w_j, p_j)}_{j=1}^{M}，其中 w_j > 0 为第 j 个沙堆的质量，
p_j ∈ R² 为其二维坐标。真实标注包含 N 个坑，记为 G={g_i}_{i=1}^{N}，每个坑的容量归一化为 1。

定义传输变量 π_ij ≥ 0 为从沙堆 j 搬运到坑 i 的质量。每个沙堆允许保留未使用的剩余质量
s_j ≥ 0，满足质量守恒：

    Σ_{i=1}^{N} π_ij + s_j = w_j,   ∀j ∈ {1,…,M}

坑 i 的实际接收总量记为

    R_i = Σ_{j=1}^{M} π_ij,   ∀i ∈ {1,…,N}

运输成本取归一化平方距离 d_ij = ‖p_j − g_i‖²₂ / S²，其中 S 为图像边长。

## 2. 损失函数

传输计划 π 由单层不平衡最优传输问题给出：

    min_{π ≥ 0}   α·Σ_{i,j} π_ij d_ij
                + β·Σ_i (1 − R_i)²
                + γ·Σ_j s_j²
                + ε·Σ_{i,j} π_ij (log π_ij − 1)

其中 α, β, γ, ε > 0 为超参数。β 项对称地惩罚坑接收量的不足与溢出；
γ 项惩罚剩余质量的销毁；熵项保证问题的良定性并赋予迭代求解器收敛速率保证。
记该问题的最优解为 π*。

各项的物理释义：

- 运输项：以平方距离度量搬运所需的功，鼓励邻近匹配，并对远距离错配施以二次重罚。
- 边缘惩罚：供给与需求两侧的边缘约束均以二次罚松弛。总质量 Σw 与需求总数 N 无须相等，
  二者之差由边缘惩罚吸收，此即“不平衡”最优传输的含义。
- 熵项：使传输计划保持正性且唯一，并使迭代求解具有线性收敛率。

## 3. 沙堆空间互斥正则

为防止全部沙堆坍缩至图像中心，引入质量加权的成对排斥势：

    L_rep = λ · Σ_{j<k} w_j w_k · exp(−‖p_j − p_k‖² / (2σ²))

其中 λ > 0 为权重；带宽 σ 取 exemplar 框中位宽高与图像边长之比。

## 4. 联合训练目标

    L_total = α⟨π*, C⟩ + β·Σ_i (1 − R*_i)² + γ·Σ_j s*_j² + L_rep

优化变量为所有沙堆坐标 {p_j} 与质量 {w_j}；π 与 s 为隐变量，由 §5 的迭代算法求得。
计数预测取搬运质量之和：

    N̂ = Σ_{i,j} π*_ij = Σ_j (w_j − s*_j)

## 5. 可微求解器

对固定的 (w, p)，§2 的熵正则化不平衡传输问题由对偶缩放迭代求解。
引入对偶变量 f ∈ R^M 与 g ∈ R^N，初始化为零，交替更新 K 步：

    f_m ← ρ₁/(ρ₁+ε) · ( −ε · log Σ_n exp((g_n − C_mn)/ε) ),     m = 1,…,M
    g_n ← ρ₂/(ρ₂+ε) · ( −ε · log Σ_m exp((f_m − C_nm)/ε) ),     n = 1,…,N

    π_mn = exp((f_m + g_n − C_mn)/ε)

其中 ρ₁ 对应行（供给侧）边缘罚强度 γ，ρ₂ 对应列（需求侧）边缘罚强度 β；
当 ρ₁, ρ₂ → ∞ 时退化为平衡 Sinkhorn 迭代。
全部 K 步展开纳入自动微分计算图，梯度沿迭代序列回传至 {p_j, w_j}，进而更新骨干网络。
数值实现采用 log-sum-exp 稳定化，并在混合精度训练中以单精度执行该子图。
