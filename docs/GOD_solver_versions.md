> 2026-08-25 存档。背景：G001_god_hf 训练 E1–E11 后做根因分析，确认当前实现
> **从未真正求解过不平衡 OT**（单步 softmax 是启发式路由器），由此产生三个版本。
> 关联：`docs/GOD_root_cause_2026-08-25.md`、`tree/nodes/G001_god_hf/`

## 共同基础（三版一致的部分）

沙堆 S={(w_j,p_j)}_{j=1..M}（M=576 token直出），坑 G={g_i}_{i=1..N} 容量=1，
d_ij = ‖p_j−g_i‖²/S²，R_i = Σ_j π_ij，剩余 s_j = w_j − Σ_i π_ij，
外层损失 Lot = α·Σπ·d + β·Σmax(0,1−R)² + γ·Σs² + Lrep(高斯互斥)。

区别全部在：**内层 π 怎么来的**。

## 版本 B —— Lead 修改版（当前线上代码，model.py:91 god_loss）

```
prob = softmax([−d²/ε, 0_dustbin])      # 行独立,一步完成
π    = w · prob[:,:N];  s = w · prob[:,N]
lot  = transport + β·deficit² + β_over·overflow² + γ·surplus² + 0.1·ε·entropy
```

工程动机：576×N 批处理省时、AMP 稳定；dustbin 列吸收多余质量。

实测后果（E1–E11 根因）：
1. **π 不是任何内层问题的解**——分配比例 π_ij/w_j 被几何+ε 冻结，与 w 无关；
2. 无列协调：多堆可同时灌满一坑 → over 单批冲 41，整体缩回 → def 爆，跷跷板 11 轮不收敛；
3. 外层拿到的是"路由器梯度"而非值函数包络梯度 → Σw 学不到每图该备多少吨；
4. 开卷 ρ 0.82→0.87 照样涨（几何是冻结特征自带的），闭卷卡死 32~39——空间会学、增益不会。

判决：**能跑通管线、暴露问题，但不是 GOD。作为对照组保留。**

## 版本 C —— 用户修改版（真·不平衡 Sinkhorn，待实现）

用户指出病根后拍板的正确形态：恢复"先解最优运输方案、再把方案当损失"的双层结构。

```
a_j = w_j          # 堆质量（行边缘）
b_n = 1            # 坑容量（列边缘）
C_mn = d²/S²       # 运费

log 域 KL 松弛不平衡 Sinkhorn，K≈5–10 步展开进计算图:
f ← τ₁/(τ₁+ε) · (−ε·LSE_n[(g_n − C_mn)/ε])     # 行更新
g ← τ₂/(τ₂+ε) · (−ε·LSE_m[(f_m − C_nm)/ε])     # 列更新 ← 坑侧协调就在这步
π_mn = exp((f_m + g_n − C_mn)/ε)
R_n = Σ_m π_mn ;  s_j = w_j − Σ_n π_jn         # 剩余量自动给出

Lot_C = α⟨π,C⟩ + β·KL(b ‖ R) + γ·KL(a ‖ πᵀ1) + Lrep
        （τ₂ ↔ β 缺额侧，τ₁ ↔ γ 剩余侧；τ→∞ 退化为平衡 Sinkhorn）
```

相对 B 版的实质变化：
1. **迭代 K 步**，行/列交替缩放——坑间竞争被显式求解，不再靠外层罚单硬拉；
2. **无 dustbin 列**：剩余由行边缘违反经 τ₁ 松弛自动承担；
3. 梯度经整条迭代链回传（unrolled optimization），信号是"改变 w/p 使**最优方案**变好"；
4. 显存 ~百MB 级（576×3000×K），3060 可跑。

预期修复：def/over 跷跷板收敛、闭卷 Σw 开始跟随 N、cnt_err 底部下降。
风险：K 步展开的训练时间 ×~3（仅 loss 部分）；τ/ε 需要重调。

**状态：已批准，待实现。实现后 B 版代码保留为 `god_loss_router` 对照。**
