# 根因分析（E1–E11 全数据，batch8 40ep 长跑）

## 一、现象：三条曲线三种命运
| 指标 | 轨迹 | 判决 |
|---|---|---|
| 开卷 Σπ | 36.4→27.7 单调降，ρ 0.82→0.87 | 空间识别持续进步 |
| 闭卷 Σw | 36→39→31.8→34→36 震荡，无趋势 | 总量校准卡死 |
| gate | 0.6647→0.6637，11轮动了0.001 | 完全没在学习 |
| α/β | +0.008/轮线性漂移 | 不是学习，是慢性漂移 |

模型学会了"往哪搬"，学不会"备多少"。四个根因按因果链排：

## RC1 门卫失灵：DINOv3 相似度没有动态范围
由 gate=0.664 反推，全部 token 的 sim 挤在 ≈0.68。DINOv3 patch 特征本来高度均匀（同图背景/目标 cos 差 <0.1），过 σ(1.0·sim) 必然窄带。而 prompt-A 只给 α、β 两个标量——就算 sim 有差距，全局仿射也只能整体抬降，永远做不出"这张图多放、那张图少放"的每图调制。

## RC2 绝对质量锚缺失：没人教过它"1 吨有多重"
训练里唯一的绝对刻度是坑容量=1.0，但要靠"搬对位置"间接反推。GOD 文档 F5 自己就指出 exemplar 框内应恰有 1 份质量——没有任何损失把"框内沙堆质量和 ≈ 1"直接教给模型。这正是文档 H-A"幅度坍缩"预言的失败模式：OT 修好了路由，没修增益。

## RC3 优化器层面：dense 批梯度被裁剪系统压死
loss 未按 N 归一 → 密图 def≈200、gnorm 冲到 90~300 → 被 clip 到 1 削掉两个数量级；Adam 的二阶动量被这些尖峰污染后，后续稀疏批的有效步长也被压小。表现就是闭卷 MAE ±3 的震荡：密批踢一脚，稀批回弹。

## RC4 算法层：单步 softmax 缺坑侧竞争
行独立分配 = 各堆互不通气，多个堆同时往一个坑灌 → over 爆（见过单批 41）；下一批又整体缩回 → def 爆。def/over 跷跷板 11 轮没收敛就是这个：没有 Sinkhorn 的列归一化来协调"谁该少给"。文档原方案正是迭代求解，一步近似把最关键的协调步省了。

## 因果闭环
RC1 门卫无范围 ─┐
RC2 无绝对锚点 ─┼→ Σw 只能停在全局均值 ~60 吨 → 闭卷卡 32~39
RC3 密批梯度被削 ┘        ↓
RC4 坑侧无协调 → def/over 震荡 → 就算备对了也分不匀
                           ↓
              但空间几何是冻结特征自带的 → ρ 照样涨到 0.87

## 处方（对应根因，按 GOD 忠实度排序）
- F1 (RC2): exemplar-box 质量锚定损失 L_box = mean_k(Σ_{p_j∈box_k} w_j − 1)² —— 直接实现文档 H-A，教绝对刻度
- F2 (RC4): 单步 softmax → log域 Sinkhorn K=5 迭代（恢复文档原算法的列协调）
- F3 (RC3): loss 按 max(N,1) 归一 或 dense/sparse 分桶采样平衡
- F4 (RC1): prompt-B sim 按图标准化 + α_init=5
- F5 (可选): 解冻 blocks10-11 @lr×0.1（旧证据 +2.0）

优先级：F1+F2 一组先上（都属 GOD 原文应有之义），F3/F4 视 E12-15 结果加。
