arXiv:2604.12999v1 - Agentic Discovery with Active Hypothesis Exploration for Visual Recognition (HypoExplore)
Rice University - Jaywon Koo, Jefferson Hernandez, Ruozhen He, Hanjie Chen, Chen Wei, Vicente Ordonez
================================================================================

ABSTRACT DISTILLED
------------------
HypoExplore formulates neural architecture discovery for visual recognition as hypothesis-driven scientific inquiry. Given a human-specified high-level research direction, it ideates, implements, evaluates, and improves architectures through evolutionary branching. A large language model creates new hypotheses by selecting a parent hypothesis to build upon, balancing exploitation of validated principles with exploration of uncertain ones. The framework maintains a Trajectory Tree (lineage of all architectures) and a Hypothesis Memory Bank (confidence scores from experimental evidence). After each experiment, four feedback agents analyze results from different perspectives and consolidate into confidence updates. Tested on lightweight vision architectures on CIFAR-10: best achieves 94.11% accuracy evolved from a root baseline of 18.91% (with 5 roots total, best initial 81.2%), generalizes to CIFAR-100 and Tiny-ImageNet. Independent run on MedMNIST achieves state-of-the-art. Confidence scores become increasingly predictive as evidence accumulates and principles transfer across lineages.

1. PROBLEM AND MOTIVATION
-------------------------
Designing strong neural architectures still requires substantial human effort. Recent LLM and multi-agent systems can automate code generation, execution, debugging, and analysis, but mostly explore via targeted modifications within constrained patterns. HypoExplore goes further: from-scratch discovery without a seed backbone or fixed search space. The deeper challenge is deciding what fundamentally new architectural idea to pursue next and on what evidential basis.

Grounded in meta-research on scientific practice:
- discovery as dual search over hypothesis space and experiment space
- maintaining multiple competing hypotheses to avoid fixation (Chamberlin, Platt, Wason)
- exploration-exploitation tension and division of cognitive labor (March, Kitcher)
Each design direction is an explicit architectural hypothesis: a structured conjecture about what mechanism may improve performance, making discovery more structured, less redundant, and more interpretable.

2. METHOD - HypoExplore
-----------------------

2.1 Overview
Discovery state S_t = { T_t, M_t } where T_t is trajectory tree and M_t is hypothesis memory. At iteration t, select parent node p_t, select hypothesis set Q_t to test, run research cycle to instantiate, execute, and analyze architectures conditioned on (p_t, Q_t). Update both memories to S_{t+1}. Discovery is hypothesis-driven, not architecture mutation within a fixed family. Structured memory decides WHERE to explore and WHAT to test.

2.2 Structured Memory
- Trajectory Tree T_t: each node v = { h_v, a_v, r_v, p_v } where h is hypothesis (or set reference), a is instantiated architecture, r is experimental outcome, p is parent. Preserves full lineage to identify promising/saturated/failing branches. Per-node storage includes: idea dict, architecture DAG, 1024-dim Weisfeiler-Lehman embedding, code attempts (model.py, config.py pairs), experiment results (accuracy, loss curves, timing, FLOPs), per-agent feedback, hypothesis tracking (tested id, prediction, evidence type/strength), scores (best accuracy, novelty, selection score, times selected).

- Hypothesis Memory Bank M_t: for each hypothesis h, maintains m_t(h) = { N_t(h), c_t(h), l_t(h) } where N is test count, c in [0,1] is confidence (bounded [0.01,0.99], init 0.5 = maximum uncertainty), l is logs (supporting evidence, contradictions, failure modes, implementation notes). Hypotheses are text in format: IF [architectural choice] IN [scope], THEN [predicted effect], BECAUSE [mechanism]. DISPROVED IF [falsification criterion]. Plus fields: scope, prediction, falsification_criteria, tags, initial_confidence, bidirectional connections, provenance (created_by, source node). Classified as confirmed c > 0.75, refuted c < 0.25, uncertain otherwise.

2.3 Per-Node Research Cycle
Given parent p_t and hypothesis set Q_t, creates up to |Q_t| children. Redundancy filtering may reject and regenerate until novelty satisfied or retry budget exhausted.

- Idea Agent:
  Root (generation 0): receives research direction + curated literature references; generates K diverse architectures from scratch in single batch LLM call (ensures inter-idea diversity). Each proposal contains title, description, intuition, novelty, architecture_spec (core_ideas, core_blocks, network_structure, tunable_aspects, invariants), and up to K_hyp new hypotheses in structured format.
  Evolution (gen >=1): receives 5 context blocks: research direction, parent architecture full brainstorming output + performance metrics, feedback summary (all agents, with hypothesis confidences), compiled hypothesis memory grouped into confirmed/refuted/uncertain, and selected hypothesis h*. Outputs reasoning trace (parent_analysis, failure_analysis, hypothesis_usage, proposed_changes), architecture fields, existing_hypotheses IDs, up to K_hyp new hypotheses. Behavior: targeted 1-2 aspect changes (not full redesign) for causal attribution; builds on confirmed patterns, investigates uncertain, avoids refuted.

- Coding Agent: receives architecture spec + implementation notes l_t(h*) (failure modes, recommended practices). Generates model.py (PyTorch nn.Module) and config.py (hyperparameter dict). Constraints: <10M params, AMP support, channels-last, training within t_max. Three modes: initial generation, error recovery (retries up to R_max=10 with traceback), hyperparameter refinement (adjusts only config.py up to F_max=5 steps with early stopping on plateau).

- Redundancy Filtering: two-stage. Stage 1: embed candidate concept description via Gemini Embedding API (256-dim) and retrieve top-k=3 most similar archived concepts in T_t by cosine similarity. Stage 2: LLM judge compares structural design principles (not surface hyperparameter differences); same innovation claim + same structural pattern = duplicate even if terminology differs. Outputs novel boolean, reasoning, most_similar_to, shared_principles, new_contribution. If rejected, Idea Agent regenerates with explicit avoid instruction, up to 2 retries.

- Executor: trains under wall-clock timeout tau_max = 30 minutes (1800s). Sanity-check 5 epochs detects catastrophic failures early. Records r = { J(a), d } where J is task performance, d is diagnostics (instability, timeout). Successful execution appends node to tree.

- Multi-perspective Feedback (4 parallel agents, all share output schema reasoning, actionable_feedback, hypothesis_updates with evidence_type in {supports, contradicts, neutral}, strength in [0,1], reasoning, new_hypotheses):
  * Quantitative: accuracy, loss curves, convergence speed, efficiency, per-class breakdown; identifies overfitting, class weaknesses, bottlenecks.
  * Qualitative (VLM): examines N_err highest-confidence misclassified images with heatmaps; method auto-detected: GradCAM (CNN-dominant), Attention Rollout (transformer-dominant), Input Gradient Saliency (fallback e.g. MLP-Mixers); analyzes texture vs shape bias, confusion patterns.
  * Causal: compares parent and child specs + structural diff + performance delta; attributes changes to modifications.
  * Diagnostic (failure/timeout only): root-cause analysis (OOM, numerical instability, excessive FLOPs); records common_failures and recommended_practices into l_t(h) for future Coding Agent use.

- Hypothesis Synthesis: single LLM call consolidates all feedbacks, deduplicates overlapping updates (synthesizes reasoning citing all agents), resolves disagreements by specificity, collapses redundant new hypotheses (capped at K_synth=2 per node). Checks misattributed updates (verifies reasoning matches hypothesis text, remaps or discards) and contradiction check (if new hypothesis is opposite of existing mechanism, convert to contradicts update instead). Quality gate: 7 dimensions must pass - mechanistic, scoped, predictive, falsifiable, novel, transferable, actionable. Failing hypotheses revised or discarded. Passes through implementation_notes from diagnostic agent.

- Memory Update: c_{t+1}(h) = c_t(h) + eta * w * (1 - c_t(h)) if supports, c_t(h) - eta * w * c_t(h) if contradicts, where eta=0.20, w in [0,1] is evidence strength. Keeps confidence bounded with diminishing increments toward 1 or 0. Update logs l_t(h) and counts N_t(h).

2.4 Dual Selection for Guided Discovery
Separates WHICH branch to expand from WHICH hypotheses to test. Parent selection deterministic for stability; exploration-exploitation tradeoff concentrated in hypothesis selection.

- Parent-Node Selection: expandable nodes V_t^exp. For each n:
  quality(n) = lambda_acc * Acc(n) + (1-lambda_acc) * (1 - min(tau(n), tau_max)/tau_max)  where Acc is normalized validation accuracy, tau is training time.
  avail(n) = 1 - |H_tested(n)| / |H_active(n)|  where H_active excludes confirmed/refuted, H_tested is already tested; 0 if no active.
  score(n) = lambda_parent * quality(n) + (1-lambda_parent) * avail(n)
  Select highest score. Used lambda_acc=0.85, lambda_parent=0.60.

- Hypothesis Selection: for parent p_t, candidate set H_cand(p_t) = hypotheses not yet tested on ancestors. Select exploitation and exploration subsets, union = Q_t (size <= 2*K_hypo, K_hypo=2 => up to 4).
  Exploitation via Thompson sampling: for each h, alpha_h = alpha_0 + sum_{e in sup} w_e, beta_h = beta_0 + sum_{e in con} w_e, with prior (1,1), uniform w_e=1; sample theta_h ~ Beta(alpha_h, beta_h); sort descending, take top K_hypo.
  Exploration via epistemic value: epistemic(h) = 1 - |2*c_t(h) - 1|, maximal at 0.5, zero at 0 or 1. Take K_hypo with largest epistemic.
  Union deduped.

3. EXPERIMENTS
--------------

3.1 Setup
Research direction: "Design a novel attention mechanism where tokens influence each other through fundamentally different connection patterns than standard all-to-all self-attention"
Agents: GPT-5-mini; temperatures: generation agents 0.7, synthesis/memory 0.3, redundancy judge 0.1; max output 32768 tokens; embedding via gemini-embedding-001. 5 root nodes, 50 iterations, single NVIDIA A40 GPU, 30 min wall-clock per experiment. Hyperparams: lambda_acc=0.85, tau_max=30, lambda_parent=0.60, Beta prior (1,1), uniform evidence weights, eta=0.20, K_hypo=2.

Training protocols:
- CIFAR-10 default (overridable via config.py, new hparams can be added): 32x32, norm mu=(0.4914,0.4822,0.4465) sigma=(0.2470,0.2435,0.2616), augmentation random flip 50% + translate +-4px reflect pad + Cutout 12x12, GPU-resident dataloader, FP16 channels-last, SGD lr 0.1 momentum 0.9 wd 5e-4 Nesterov, cosine annealing + 5 epoch warmup, label smoothing 0.1, grad clip 1.0, batch 1024, error recovery up to 10 retries, HP refinement up to 5 steps.
- MedMNIST: DermaMNIST 7 classes, 224x224, grayscale->RGB, norm 0.5, augmentation RandomResizedCrop 224 + AugMix sev3 width3 alpha0.4 + RandomHorizontalFlip p0.4, SGD same defaults, FP16, batch 128, 4 workers, same budgets.

3.2 Main Results - CIFAR-10 trajectory tree and accumulated best accuracy
Figure shows 5 root branches with distinct trajectories; one branch driven by key hypotheses like Hyp_44 achieves decisive leap to best architecture.
- All methods share same 5 roots (best initial 81.2%). HypoExplore reaches 81.28% by iteration 15, 93.57% by 18, 94.11% by 45, steady improvement.
- Full system outperforms ablations (each curve removes one component):
  * Without hypothesis-driven search (only accuracy+time for parent): initially outpaces but quickly saturates without accumulated knowledge.
  * Without multi-agent feedback: rapid early gain then stagnation, cannot diagnose why architectures succeed/fail.
  * Without hypothesis selection: steady but limited progress, memory accumulates but cannot direct exploration.
  * Without parent selection (greedy accuracy): similar to without hypothesis-driven search, confirms intelligent parent selection critical to escape local optima. All plateau well below 94.1%. HypoExplore slower start reflects cost of exploring uncertain hypotheses that later pays off.
- Parent selection strategy comparison (other components fixed):
  Exploration-Exploitation annealing (50% exploration annealed to exploitation): fastest early discovery but saturates, fixed schedule cannot adapt.
  Greedy: earliest and lowest plateau (exploitation collapse).
  DGM-style (fitness weighted + novelty bonus inverse to offspring count): slightly better than greedy.
  Random: outperforms greedy and DGM-style, showing hypothesis memory + feedback make even undirected exploration effective.
  HypoExplore only one that continues improving, grounding exploration in accumulated knowledge.

4. ANALYSIS
-----------

4.1 Discovered Architectures - three representative highest accuracy, each efficiently aggregates global context without quadratic attention:
- GSTN (94.11%): Global Shape Token Network. Lightweight 3-stage ResNet backbone + Global Shape Token module with small bank of learned global vectors as intermediaries for sparse global routing. Spatial features softly assigned via cosine similarity, aggregated signal residually blended back, content-adaptive global context without attention at O(G x N) cost. Related to inducing points and register tokens.
- Hierarchical Hub Routing Network (HHRN, 93.57%): replaces dense attention with hub-mediated sparse routing. Tokens softly assigned to small set of learned hub vectors via cosine similarity; hubs aggregate, exchange via sparse GNN with top-k adjacency, broadcast refined corrections back. Token-to-hub related to Slot Attention, hub-to-hub GNN related to Vision GNN.
- Band-Aware Wavelet Token Mixer (BA-WTM+, 91.22%): explicit frequency-domain decomposition splitting features into low/high channel halves via learned analysis transform; FiLM controller conditioned on low stream modulates high bands, sigmoid-gated cross-band residual lets low-pass shape priors suppress spurious high-frequency textures. Uses only 1x1 and depthwise convs, no attention. Related to Octave Convolution and WaveMLP.

4.2 Discovered Hypotheses
117 hypotheses accumulated: 19 confirmed (confidence >0.7), 95 uncertain, only 3 refuted. Standout confirmed:
- hyp_44 (confidence 0.601, 3 supporting / 2 contradicting), directly informed best architecture: adding as few as 3-4 small learnable global tokens that collect spatial summaries and broadcast shape-aware updates is sufficient to break texture dominance, surprisingly economical.
- hyp_17 (0.830, 3/0): separating shape-oriented and texture-oriented token channels into dedicated representation banks, each compressed at natural rate, recovers ability to attend to global object outlines in shape-reliant classes.
- hyp_26 (0.717, 3/0): introducing small learnable positional offsets into feature transform pipeline gives subtle spatial position sense, enabling distinguishing asymmetric/location-dependent patterns at negligible cost.

4.3 Hypothesis Prediction Accuracy (calibration)
Measure whether hypothesis correctly predicts direction of accuracy change vs parent. Bin hypothesis-experiment pairs by confidence at testing:
[0.25,0.5) : 58% correct (N=24)
[0.5,0.75): 65% (N=109)
[0.75,1.0] : 80% (N=30)
All exceed 50% chance, monotonic trend shows confidence scores are meaningfully calibrated, not artifacts. Lowest bin empty indicates no retained hypotheses lacking supporting evidence.

4.4 Knowledge Accumulation over Generation
Best accuracy and validated hypothesis count (thresholds 0.6 and 0.75) co-move over chronological experiments. Major jumps between nodes 15-25 (85% to 93.5%) coincide with rapid increase in validated hypotheses at 0.6 threshold. After node 30 both plateau, slight increase around 45 with final accuracy gain. Pattern consistent with explore-then-exploit: early builds foundational knowledge, mid diversifies (temporarily weakens correlation), late consolidates into top architectures. Discovery slows as hypothesis space becomes explored.

4.5 Cross-Lineage Knowledge Transfer
5 independent evolutionary lineages from different roots. Classify each hypothesis application as within-lineage (same root lineage) vs cross-lineage (different lineage). Cross-lineage succeed at 65% (N=171), comparable to within-lineage 57% (N=93). Cross-lineage applied nearly twice as often, indicating selection actively shares knowledge across branches. Demonstrates hypotheses capture transferable principles not lineage-specific artifacts.

Prompt contracts summarized: Idea root requires exactly K DISTINCT architectures, hypothesis-driven, each introduces new structural principle grounded in inductive bias/geometry/optimization/representation, 95% CIFAR-10 target, better efficiency than ResNet-50, ~1 min training. Evolution Idea analyzes parent strengths/weaknesses and tests hypotheses with 1-2 changes. Coding enforces no loops over tokens, no where+scatter, prefer Conv2d/BN/GroupNorm/pooling/einsum/matmul. Synthesis deduplicates and checks contradictions. Diagnostic distinguishes timeout/OOM as contradicts vs code bug as not_testable.

6. CONCLUSION
-------------
HypoExplore reframes automated neural architecture discovery as hypothesis-driven scientific inquiry. By maintaining trajectory tree and hypothesis memory bank, it separates where to search from what to test, answering both with empirical evidence rather than undirected trial-and-error. Yields GSTN 0.9M params 94.11% CIFAR-10 that transfers competitively, accumulating transferable design knowledge whose predictive accuracy grows with confidence. Core insight that autonomous systems should reason explicitly about what is known and what remains uncertain extends beyond architecture search to machine-driven scientific discovery.
