## §1 第一性原理：网络真正能"看到"的量是覆盖率 f
ViT-S/14 把图像压成 cell 网格后，对亚 cell 尺寸物体，位置信息丢失，剩下的可观测量只有：每个 cell 被目标类占据的概率 → 覆盖率 f = 被占面积/总面积。
随机放置、半径 r 的圆盘泊松布尔模型给出精确闭式：
```
f = 1 − exp(−λ·π·E[r²])      ⟹      λ = −ln(1−f)/(π·E[r²])，  N = λ·A
```
f 是 [0,1] 有界的——这就是压缩的数学本体：λ 大时 f 饱和，任何对 f（或其线性组合）做线性回归/全局校准的读出都必然在高密度端塌缩。而反演公式在 f→1 时发散，恰好是物理正确的"越挤越敏感"。r 由 exemplar box 免费提供（E[r²] 可从3个box估计）。周长、欧拉示性数等其它可测量各有闭式（Miles 型公式；常数不背书，用蒙特卡洛圆盘模拟一次性标定），可作交叉校验与簇集/规则排列的诊断（分量数偏离泊松预测⇒Matérn簇或硬核过程的二参推广）。

## §1.5 数学附录（推导 + 动力学分析）
**(a) 覆盖率公式推导（含随机半径的偏差项）**
点 x 未被覆盖 ⟺ 半径 r 内无圆心 ⟹ `P(未覆盖|R=r)=exp(−λπr²)`。随机半径时对 R 取期望：
`f = 1 − E[e^{−λπR²}]`，由凸性 `≥` 不等号方向给出 **f ≤ 1−exp(−λπE[R²])**。
用 `Ê[R²]` 天真反演的一阶相对偏差（对 f 展开到二阶）：
`λ̂/λ ≈ 1 − ½(κ−1)·(−ln(1−f))`，其中 `κ=E[R⁴]/E[R²]² ≥ 1`。
数值：±20% 尺寸波动 ⟹ κ≈1.05（注意 κ=CV(R²)²+1，平方放大离散）；中等离散 CV(R)≈30% ⟹ κ≈1.4 → f=0.5 时偏差 ~14%；重尾 κ=2 → 35%，且随密度增大而放大。**结论：尺寸离散是系统性低估的主源，必须用第二方程消去**（边界长度密度 `L_A=λ(1−f)·2πE[R]` 与覆盖率联立解 `(λ, E[R], E[R²])`，即 Weil(1988) 矩方法三方程；其已知偏差由 R0-B 直接量化）。
**审查补充两条**：① `E[R²]` 只能从3个 exemplar box 估计，相对误差 ≈ CV(R²)/√3，单图可达 30%+ ——需跨同类簇收缩估计或干脆依赖边界长度方程；② 边缘效应：窗界外圆心贡献窗内覆盖，系统偏差量级 ~周长×r/A ≈ 6%@392px、r=6px，oracle 测试会把它一并计入。

**(b) 误差传播 / 反演稳定性（修正§3的错误论断）**
`N̂ = A·g(f̂)`，`g(f)=−ln(1−f)/(πμ₂)`，`g′=1/(πμ₂(1−f))`。有效独立采样数 `n_eff ≈ A/(c·πr²)`（占用场相关长度~r，c≈3）。伯努利测量噪声传播：
`CV(N̂) = √f / (√n_eff·√(1−f)·(−ln(1−f)))`
逐点计算：f=0.3→1.83、f=0.5→1.44、f=0.8→**1.24（最小）**、f=0.9→1.30、f=0.99→2.16、f=0.999→4.58、f=0.9999→10.9（均除以√n_eff）。
取 n_eff≈450：f=0.99 时统计 CV≈10%，f=0.999 时 22%。**审查修正：CV 在 f→1 处渐近发散**（令 ε=1−f，`CV ~ 1/(√n_eff·√ε·|ln ε|)→∞`），并非"根本不爆炸"；准确表述是发散极迟——实用区间 f≤0.95 内系统性偏差仍占主导，深饱和区（f>0.99）测量噪声与系统偏差叠加。§3 原"方差爆炸"表述过强、"不爆炸"表述过弱，以本段阶梯为准。
最优工作点的推导：令 d(ln CV)/df=0 ⟹ `1 = 2f/(−ln(1−f))` ⟹ 解得 **f*≈0.797**。这是场景固有属性（由 N 和物体尺寸决定），不是可调旋钮。

**(c) 尺度不变性定理 → 推翻我自己§2的路由规则**
把图像从 392 重采到 S 像素评估：`λ(S)=N/S²`，`r(S)=r₀S/384`，故 `λ(S)πr(S)² = Nπr₀²/384² ≡ const` —— **理想测量的覆盖率与分辨率无关**（上采样不产生新信息）。因此"选分辨率把 f 调进敏感带"在数学上不可能，§2 原路由规则作废。那为什么 H0035/36 实测高分辨率有效？因为实测 f̂ 偏离真 f 的量是 token 网格混合误差，随网格变细而降——分辨率的作用是**降低测量偏差**而非改变 f。由此得到更干净的操作判据：
**跨分辨率自洽路由**：`|f̂@res₁ − f̂@res₂| < τ` 则低分辨率可信；否则升分辨率直至 f̂ 稳定。经验阈值平台期(150–300)的存在性是该判据的必然推论。

**(d) 排列非泊松的方向预言（可证伪）**
簇集（吸引相关，鸟群）：给定 N 时重叠多于泊松 ⟹ f 偏低 ⟹ 反演低估。规则排列（排斥相关，货架网格）：重叠少于泊松 ⟹ f 偏高 ⟹ 反演高估。我们 dump 里尾部是严重**低估** ⟹ 若排除幅度饱和解释后仍低估，则预言主导偏离为簇集型——R0-B 可直接检验该符号。

**(e) 训练动力学：为什么 BCE 占用图不会重蹈 0.03–0.19**
密度回归的病理不是损失几何本身（位置混合的密度积分仍守恒），而是**梯度信号-压力失衡**：GT 密度图仅 ~1–5% 像素非零，奖励质量的梯度信号被 weight decay/表征压力碾平，头部输出幅度收敛到坍缩平衡——这解释了质量亏损为何随物体像素面积减小而加剧（大物体稀疏图质量接近1，小物体密集图 0.03）。BCE 占用目标翻转了信噪比：密集区 30–60% 的 cell 携带 O(1) 概率信号，且目标是概率、无幅度标度可言。可检验推论：exemplar-box 质量应与物体像素面积正相关（dump 可验）。

**(f) 训练动力学的定量玩具模型（幅度坍缩的平衡点）——数值已实测校准**
最简模型：头部对正密度像素输出幅度 a，目标高度 h，显著正像素占比 p，衰减映射 μa²。损失 `L=p(a−h)²+(1−p)a²+μa²`，dL/da=0：
`a* = p·h/(1+μ)`
**实测代入**（2026-08-24 服务器抽样300张train GT图）：`p` 中位 **0.055**（IQR 0.026–0.090，阈值0.1×峰值）；冠军配置 `weight_decay=1e-4` ⟹ μ≈0 ⟹ **a*≈0.055h**。与实测 exemplar-box 质量 0.03–0.19 同量级。审查声明两条：① 玩具模型描述训练分布边缘的幅度标定；字面成立将预言稀疏图整体缩水，与稀疏计数准确矛盾——机制A只约束"超出训练支撑的高密度需求"，分工由 dump 检验（box质量 vs 物体面积相关方向）。② 实测量是**积分比**、玩具预测的是**峰值比**，两者相等需假设空间展布相近——量级论证而非精确等式。
机制B（压缩曲线来源）：位置不确定度 σ 增大时乘性衰减 `b=τ²/(τ²+σ²)` 预测压缩随密度单调恶化——§0表格 0.96→2.22 的形状。
BCE 免疫性：正例占比=f 本身（敏感带内约30–80%）。

**(f2) 数值假设的实测替换记录（原为拍脑袋，现已钉死）**
| 量 | 原假设 | 实测 | 结论 |
|---|---|---|---|

**(g) 推理期动力学：跨分辨率一致性是个收敛过程**
f̂(S) 随 token 网格 S 变细单调收敛到真 f（测量偏差 b(S)↓，H0035 的尾部单调改善是其经验证据）。一致性间隙 `δ(S)=|f̂(S₁)−f̂(S₂)|` 是当前偏差的可观测量代理，路由停止条件 `δ<τ` 即为不动点判据；无需保证 δ 单调，只需可测。

## §1.6 定理级弹药（已证明的数学结论 → 一针见血的决策规则）
**A. 连续渗流相变（Hall 1985；Meester–Roy《Random Geometric Structures》定理级结果）——最锋利的一根**
二维重叠圆盘布尔模型在 `θ_c = 1−exp(−η_c) ≈ 0.676`（`η_c=λπr²≈1.128`）处发生**严格相变**：f<θ_c 时占用集以有限分支为主（分量数~个体数），f≥θ_c 时出现贯穿整图的巨分支。
一针见血之处：它把"密集图难数"从质量抱怨升级为**可判定的逐图机制分类**——
- bulk图（f≪0.68）：亚临界，"个体"存在良好，任何合理读出都该准（实测bulk MAE 3–9 ✓）；
- 尾部图（f→0.5–0.7）：恰在临界窗内，涨落最大、簇相关性主导——75.9% SSE 集中于此不是偶然，是临界现象；
- f≥θ_c：巨分支吞并个体，**"数个体"问题本身不适定**，唯一有意义的量是强度 λ ——正是反演读出的领地。
顺带严格击毙拓扑范式的高密度野心：Betti-0 计数在 f>θ_c 后必然失效，且是突变不是渐变。同时给出**逐图读出选择器 v3**：f̂<θ_c−margin 可直接数连通分支（更便宜更稳）；f̂≥θ_c 强制走反演。注意与§1.5(c)尺度不变性自洽：物理 f 不随分辨率变——分辨率改变的是测量质量，不改变相区归属。

**B. Hug–Weil 唯一性（Adv. Appl. Prob. 33 (2001) 39–60；d=2,3）——适定性证书**
平稳布尔模型的本征体积密度 {Vⱼ} (j=0..d) **唯一确定**粒子过程强度 γ 与典型颗粒矩。即：面积分数+边界长度+欧拉三个观测联立解 `(λ, Ā, Ū)` 不存在伪解——反演是适定的，不是拟合巧合。这把"多解担忧"从工程问题降格为不存在的问题。

**C. Laslett 定理 + M/G/∞ 对应（Laslett 1983；queueing 经典）——高密度的无偏估计通道**
一维扫描线上的布尔模型 ≡ M/G/∞ 排队：泊松到达=圆心、服务时长=颗粒长、合并区间=忙期。Laslett 定理保证切点经变换后恢复同强度泊松结构。实操含义：对占用图做行扫描，拟合**分量长度分布的形状**（M/D/∞ 有闭式 Laplace 变换；我们实测 CV(R)≈0.224 支持窄分布近似）即可估计 λ——用分布形状而非两个矩，绕开 Weil(1988) 矩方法的已知偏差，比 van Lieshout 的 MCMC-MLE 便宜几个数量级。尾部桶 [500,∞) 的专用升级件，CPU 即可跑。

**D. 配套三件（支撑角色）**
Hadwiger 表征定理：本征体积是仅有的平移旋转不变可加赋值 ⟹ {面积,周长,欧拉} 是随机集的**完备正则测量基**，选它们不是品味是定理。Robbins 定理：软欧拉可测。Slivnyak–Mecke/Campbell：以上所有公式的推导机器。Cramér–Rao（数值化）：给定占用图观测下 λ 的 Fisher 信息 → 任意估计器的方差下界 = **停止判据**——若 R0-C 后 CR 下界仍高于 MAE≤10 所需精度，则该分辨率/该图的信息论天花板已到，加架构无益。

**综合决策树（定理背书版）**：每图估 f̂ → f̂<θ_c−margin 走分量计数 / θ_c≤f̂ 走覆盖反演（+可选C通道）/ 深饱和 f>0.95 且 C 通道分歧 → 报告信息上限。每一分叉都有定理署名，不再有经验阈值的独断。
## §2 提案：占用-反演读出 OIR (Occupancy-Inversion Readout)
把学习问题从"回归幅度"改成"预测占用 + 解析反演"：
1. **学习目标改为 exemplar 条件占用图 o(x)∈[0,1]**（BCE 监督，GT 占用由 GT 密度图阈值重建）。占用是伯努利量：**无幅度天花板、无质量标度需要锚定** —— DISTILLED 事实#3 从根上消失。
2. **计数不在网络里**：f̂ = mean(o)，N̂ 由 §1.5(a) 的三方程组联立解出（含尺寸离散校正），网络只负责它擅长的（空间判别）。
3. **分辨率路由（按§1.5(c)修正版）**：跨分辨率自洽判据 `|f̂@392 − f̂@518| < τ → 用392`，否则升辨率至 f̂ 稳定。经验阈值平台期(150–300)的存在性是该判据的必然推论。
4. 参数预算不变（复用冠军 backbone+FiLM exemplar 注入，head 输出1通道 sigmoid），~23M。

## §3 诚实的失败模式（预注册，按§1.5推导修正）
- 极端重叠图（f>0.99，推算约 GT>1500@392px）：统计CV按§1.5(b,f2)尺寸分档 10–34%，且系统性偏差被 −ln(1−f) 放大、矩方法偏差深饱和区失稳——预期只能部分修复 [600,∞)；彻底修复需更高 token 网格密度或承认信息上限。
- 尺寸离散：一阶偏差 `½(κ−1)(−ln(1−f))` 已推导（§1.5a）；κ=1.5、f=0.5 时低估17% —— 必须用边界长度方程联立消去，单方程天真反演注定失败。
- GT 占用重建有阈值伪影 → R0 用 oracle 扫阈取上界，上界不行就杀，不给借口。

## §4 R0 kill-gates（锁死，不得改）
- **R0-A 估计器自洽**（CPU 10min）：合成泊松圆盘图，反演误差 <5%。 sanity。
- **R0-B oracle 上界**（CPU 20min）：GT 密度图→oracle 最优阈值→f→反演（r 取真值）。PASS IF val Spearman>0.9 且 [300,∞) 桶 rel-err 中位 <40%。FAIL ⇒ 整个估计器类出局。
- **R0-C 可学习性**（GPU 25min）：冻结冠军 backbone + 2层头 + sigmoid，BCE 训占用图 10ep。PASS IF cell-AUROC>0.80 且反演后 val MAE ≤24（即25分钟训练就贴平40分钟冠军，否则读出无红利）。
- 节点假设（过门后才注册）：IF OIR 读出替换幅度密度头 IN 冠军谱系 THEN routed val MAE ≤16.5 且 tail[500+) ≤250 BECAUSE 计数=覆盖率解析反演（无幅度饱和，质量由构造锚定）。DISPROVED IF routed ≥19.2 或 bulk[0,75) 劣化>0.5。

## §5 查证结果（2026-08-24 全网检索）
**数学确实全老**，且比§1写的更现成：
- 覆盖率反演强度是 Matheron(1975)/Miles(1976)/Weil(1988) 的矩方法三方程组：`p=1−exp(−λ·Ā)`、边界长度密度 `L_A=λ(1−p)Ū`、欧拉密度 `χ_A=λ(1−p)−λ²Ū²/(4π)` ——三个观测量联立可直接解出 `(λ, Ā, Ū)`，连蒙特卡洛标定都不用。见 Gallego & Simó (Image Anal Stereol) 与 Hug-Last-Weil 综述 arXiv:2308.05861。
- 极端重叠下"被完全盖住的粒子不可辨识"问题有正式解：van Lieshout & van Zwet (2000) bombing-model 强度的 MLE（coupling-from-the-past）；Weil 矩方法已知有偏——R0-B oracle 测试直接量化这个偏差。
**但映射无人占据**：
- 计数文献全部是 密度回归/检测/匹配/生成式；显微细胞计数也全是密度回归或分割计数（ilastik、FCRN、Count-Ception 等），无随机集反演。
- 最近邻是 Rajan et al. "Cox Processes for Counting by Detection"（CNN 分类器输出→点过程强度贝叶斯估计）：精神相近但假设实例可分（blob 可数），无布尔并的反演、无 exemplar 条件、未上过 FSC147。
- 材料科学用 germ-grain 模型合成训练图做分割（Altendorf et al.）——方向相反（模型→数据，非 数据→计数）。
**新颖性辩护词定稿**：诊断（饱和压缩曲线驱动读出设计）+ 映射（exemplar→grain尺寸 r、占用头→覆盖率 f、Davy-Miles 三方程→N）在 CAC 中未被占据；引用源头写立体学教材而非计数论文，novelty_check 应近零命中。风险如实预注册：矩方法偏差、非泊松排列（簇集/规则网格）需二参推广、f>0.99 深饱和区测量噪声与系统偏差叠加（CV阶梯见§1.5b）。

## §6 具体设计：OIR-Net（~24.3M / 预算32M）
```
图片(392²)
   │
DINOv2-S/reg4（timm，22M，dynamic_img_size）
   ├─ 冻结 blocks 0-9            ← 时标分离杠杆 H0032✓
   └─ 微调 blocks 10-11 @lr×0.1   ← 已验证唯一可训范围
   │
block6 + block11 特征拼接 → 784格 × 768ch
   │

   → FiLM逐通道scale/shift调制全部token          ← 替代N0028未完成的余弦门控
   │
颈部 Conv3×3 768→256→128（GroupNorm+GELU，~2M）  ← 不上采样，保持28×28
```

## §7 推理流程（网络画地图，公式算数量）
1. 前向一次：392÷14=28 → 784格占用概率 ô
2. `f̂ = mean(ô)` —— 数学可观测量到手，网络使命结束
3. 尺寸从框白拿：`πr̂² ≈ mean(框宽×框高)·κ_corr`（κ_corr≈0.8-1 合成盘标定一次）
4. 反演：`λ̂ = −ln(1−f̂)/(πr̂²)`，`N̂ = λ̂·A`。无饱和：f̂高一点 N̂ 就大一点
5. 自检A · 方程对账：从ô梯度模量软边界长度（第二方程），与f联立解出不依赖框的 (λ,尺寸)；两套答案差>30% → 标记偏离随机放置假设（强簇集/网格），该图降权或回退冠军读出
6. 自检B · 跨分辨率一致性：同图518px再跑一遍，`|f̂₃₉₂−f̂₅₁₈|<τ(0.03)` 则收工，否则取大图——替代经验阈值200的新路由（平台期存在性由此预言）
7. 相区选择器（§1.6A定理背书）：f̂<θ_c−margin(≈0.63) → 该图亚临界，可直接数连通分量交叉验证；f̂≥θ_c(0.676) → 反演强制；f>0.95且C通道分歧 → 报告信息上限。逐图分派，不再一刀切。

与老推理对比：密度求和（幅度会塌）→ 概率平均+代数（无幅度概念）；无自检 → 双重自检全带诊断量。

## §8 损失函数规格（一项，处处故意）
```
L = −(1/784) Σ_c [ w·t_c·log ô_c + (1−t_c)·log(1−ô_c) ]      SoftBCE，仅此一项
```
- **软标签 t_c∈[0,1]**：GT密度图低阈值二值化（τ≈2–5%峰高，oracle扫阈定默认）→ 14px平均池化 → 格子被盖面积比。硬0/1会毁掉面积比例信息，反演即失准。
- **BCE的唯一合法性与交接点**：BCE是严格合适评分规则，极小化解=条件概率 P(被盖|特征) —— 正是公式假设网络在估的量；公式要求无偏f̂ → proper scoring rule保证。
- **pos_weight w**：负/正格子比，训练集统计固定值预注册（不用per-batch）。
- **排除项及前科**：① 密度MSE——平衡点 a*≈p·h/(1+μ)=0.055h 实测级坍缩（§1.5f）；② 计数回归头——标量头重新引入幅度天花板；③ |N̂公式−GT| 直优最终指标——把代数搅进梯度，仅R2消融臂。
- **免费自平均性质**：计数只需 mean(ô) 对，不需每格准；概率误差零均值时784格平均自动抵消。老范式幅度缩水会被积分放大，无药可救——这是结构性优势非调参运气。
- Dice锐化项不进R1（扭曲边际校准=伤命根子），预注册为AUROC停滞时的R2预案。
