# SeqCount 创新点总结
> 分为**范式创新、技术创新、机制创新、实验层面创新、局限与未来切入点**，适合写论文笔记、开题、综述引用。

## 一、范式层面核心创新（最高贡献）
1. **任务范式转换：把类别无关计数CAC从密度图回归改为序列生成任务**
现有绝大多数CAC依赖高斯核生成密度图做回归，手工高斯核很难适配物体尺寸、形状差异大的开放场景；**SeqCount是首个将序列建模引入类别无关计数的工作**，完全去掉高斯核手工设计，规避核函数与目标物体尺度不匹配带来的性能下降。
> 旧范式：图像 → 密度图回归 → 积分求和得到总数
> 新范式：图像分块 → patch级离散计数token序列 → Transformer自回归预测序列 → 序列求和得到总数

## 二、技术模块创新
2. **点标注序列化方案（Serialization Scheme）**
- 将图像均匀切分为 $N\times N$ patch，每个patch统计内部物体数量，得到整数计数token；按行优先把二维patch矩阵展平成一维有序序列；增加`Start`、`End`特殊标记控制序列生成起止。
- 优势：patch内部物体尺度、密度变化远小于整张图，离散整数预测比密度回归更容易学习；输出是可解释的分块计数矩阵，不仅能得到全局总数，还保留空间分布信息。
- 词表轻量化：词表仅对应patch内物体的计数值，词表规模远小于NLP大模型，内存开销低。

3. **Encoder‑Decoder Transformer架构适配CAC任务**
- Encoder：复用SCB+FEB模块完成查询图与示例(exemplar)的相似性特征融合，再通过Transformer Encoder挖掘特征对应关系。
- Decoder：**因果掩码自注意力建模patch之间的上下文依赖**，捕捉相邻分块的计数关联；**交叉注意力让每个token预测自适应聚焦图像对应局部区域**，缓解物体跨多个patch分割造成重复计数或漏检问题。
- 训练目标改为token分类，使用交叉熵损失，不再使用密度回归常用MSE损失。推理自回归生成完整序列，全部token相加得到最终计数结果。

## 三、机制层面带来的能力增益
4. **对物体尺度、形状变化鲁棒性更强**
实验把测试集划分为物体尺寸方差低/高两个子集：传统方法在物体尺寸差异大（High‑STD）集合性能大幅跳水；SeqCount性能衰减明显更小，证明免核+分块序列建模更适配异构开放场景。
5. **显式建模局部空间依赖，而不是各局部独立预测**
消融实验：去掉注意力，每个patch独立预测，MAE、RMSE显著变差。说明利用patch之间相关性，能有效处理物体跨patch分割、局部遮挡等现实问题。交叉注意力可视化也证实：预测某个token时注意力会落在对应图像块以及邻近相关区域。

## 四、实验与工程创新
6. **多套数据集充分验证泛化能力**
同时在**多类别CAC数据集（FSCD‑LVIS、UAVVIC、FSC‑147）**和**车辆专用计数数据集（TRANCOS、CARPK、PUCPR+）**验证；不仅评估全局MAE/RMSE，还使用GAME指标评估局部分块计数精度，SeqCount在局部指标上提升巨大，证明patch级别预测质量高。
7. **分析长尾高密度样本问题，给出增强基线SeqCount+**
真实计数数据集存在长尾：高密度样本极少。对比SOTA，SeqCount从低密度到高密度场景性能涨幅倍数更低；引入mosaic数据增强得到SeqCount+进一步提升高密度场景效果。
8. **效率权衡：Transformer架构下保持可控计算开销**
对比同类型Transformer‑based CAC方法CACVIT：SeqCount参数量与GFLOPs更低；推理53ms，具备实时应用潜力；同时指出自回归推理是瓶颈，未来可以做并行生成加速。

## 五、现有局限（可作为后续研究创新切入点）
1. 词表是预定义的，如果测试时patch中物体数量超过训练见过最大值，模型无法预测，出现失败样例。
2. 固定patch划分：patch切分粒度是超参；划分过细物体被切碎，划分过粗patch内物体太多。未来可研究**自适应patch划分**。
3. 高密度样本长尾分布仍是痛点；提出可以结合SAM分割做测试时校正、测试时归一化等方向。


## SeqCount 方法部分（Section 3）

---

### 3.1 问题定义与整体框架

**CAC 问题形式化**:
- 训练集 $D_{train} = \{(X_i, B_i, P_i)\}$，其中 $X_i \in \mathbb{R}^{H \times W \times C}$ 为查询图像，$B_i = \{b_1,...,b_{k_1}\}$ 为 exemplar 边界框，$P_i = \{p_1,...,p_{k_2}\}$ 为点标注
- 测试集类别与训练集不相交：$Class_{train} \neq Class_{test}$
- 目标：用少量 exemplar 将训练类学到的计数能力泛化到新类别

**整体流程**（图2）:
```
Query Image + Exemplars → ResNet Backbone → 特征融合(SCB+\(F^E\)B)
→ Transformer Encoder → similarity-aware feature F^E
→ Transformer Decoder(自回归) → 计数token序列 → 求和 = 最终计数
```

---

### 3.2 点标注序列化（核心创新）

**Patch 划分**: 图像均匀分为 $N \times N$ 个 patch（默认 $10 \times 10$），每个 token $c_{i,j}$ 表示对应 patch 内点标注数量。

**Row-by-row 展平**:
$$C = [c_{1,1}, ..., c_{1,N}, c_{2,1}, ..., c_{N,N}]$$

**特殊 token**:
- `Start`: 启动生成
- `End`: 生成结束标志

**训练/推理输入输出**:
| 阶段 | Decoder 输入 | Decoder 输出 |
|---|---|---|
| 训练 | `[Start, C₁, C₂, ..., C_{\(N \times N\)}]` | `[Ĉ₁, Ĉ₂, ..., Ĉ_{\(N \times N\)}, End]` |
| 推理 | `[Start]` | 自回归生成直到 `End` |

**词表设计**:
- 词表 $V = \{v_1, ..., v_K\}$，每个词对应一个整数（patch 内物体数）
- $K$ = 数据集中单 patch 最大物体数（FSC-147 在 8×8 下仅 300，远小于 NLP 模型）
- 风险：测试时出现训练未见过的大 token 值 → 缓解：多尺度 patch 划分训练

---

### 3.3 架构

#### (1) Encoder

**特征融合模块**（复用 SA\(F^E\)Count 的 SCB + \(F^E\)B）:
$$F^A = \(F^E\)B(F^X, F^B, SCB(F^X, F^B))$$
- $F^X$: 查询图像特征图
- $F^B$: exemplar 特征图
- SCB (Similarity Comparison Block): 计算图像与 exemplar 的相似性
- \(F^E\)B (Feature Enhancement Block): 基于相似性增强特征

**Transformer Encoder**:
- 输入：$F^{A'} \in \mathbb{R}^{B \times HW \times C}$（flatten + 位置编码）
- 6 层标准 Transformer Encoder，通过自注意力学习特征级对应关系
- 输出 $F^E$ 送入 Decoder

#### (2) Decoder

**因果 Transformer Decoder**（6层）:
1. 输入序列 → Word Embedding + 位置编码
2. **Masked Self-Attention**（causal mask）: 捕获 token 序列长程依赖，保证自回归性（仅看前文 token）
3. **Cross-Attention**: 将视觉特征 $F^E$ 融入，生成每个 token 时自适应关注相关视觉 patch
4. MLP → softmax 概率向量

**预测公式**:
$$\hat{o}_i = MLP\left(Dec(F^E, Start, C_1, ..., C_{i-1})\right)$$
$$\hat{C}_i = \underset{\hat{C}_i \in V}{\arg\max} \log \hat{o}_{i,j}$$

**损失函数**（交叉熵）:
$$L = -\frac{1}{N \times N} \sum_{i=1}^{N \times N} \sum_{j=1}^{K} o_{i,j} \log(\hat{o}_{i,j})$$
其中 $o_{i,j}$ 为 one-hot 编码（$C_i = v_j$ 时为 1）

---

### 3.4 推理

1. 仅输入 `Start` token
2. 自回归逐 token 生成，每步用已预测序列 `[Start, Ĉ₁, ..., Ĉ_{i-1}]` 替代训练时的真值
3. 公式:
$$\hat{C}_i = \underset{\hat{C}_i \in V}{\arg\max} \log P(\hat{C}_i = v_j \mid F^E, Start, \hat{C}_1, ..., \hat{C}_{i-1})$$
4. 生成 `End` 后停止，最终计数:
$$\hat{Y} = \sum_{i=1}^{N \times N} \hat{C}_i$$

---

### 实现细节速查

| 配置项 | 值 |
|---|---|
| Backbone | ResNet（COCO 检测预训练） |
| Encoder | 6层 Transformer + 4层 SCB/\(F^E\)B |
| Decoder | 6层因果 Transformer |
| Patch 划分 | \(10 \times 10\)（TRANCOS 用 8×8 以适配 GAME 指标） |
| 序列长度 | 101（100 计数 token + Start/End） |
| Exemplar 数量 | 3 |
| 优化器 | AdamW, lr=1e-4, warmup 10 epoch, 线性衰减至 1e-5 |
| Backbone lr | 主 lr 的 10% |
| Batch size | 8 |
| Epochs | 100 |
| 数据增强 | SeqCount: 随机水平翻转；SeqCount+: 同 CACVIT（含 mosaic） |
